# SEO-аналіз laboratorium. (школа IT / кібербезпеки)

## Висновок

Технічний і on-page SEO підсилено під запити на кшталт **«школа кібербезпеки»**, **«курси пентесту»**, **«CTF навчання»**.  
«В топ Google» одним релізом коду не гарантується: потрібні індексація, зовнішні згадки та стабільний контент. Нижче — що вже зроблено і що далі дає найбільший ефект.

## Що вже прокачано в коді

| Шар | Зміни |
|-----|--------|
| Title / description | Фокус на школу IT і кібербезпеки, без B2B-шуму |
| Schema.org | EducationalOrganization, WebSite, FAQPage, динамічний ItemList/Course |
| Course pages | SSR title/description + Course + BreadcrumbList |
| Sitemap | Головна (daily), manuals, курси з lastmod |
| Robots | Дозволені публічні сторінки, закриті кабінет/адмінка |
| FAQ | Видимий блок + JSON-LD для rich results |
| Internal links | Навігація: про школу → програми → bounty → FAQ → контакти |
| Canonical / hreflang | uk + x-default на головній |
| OG/Twitter | og-cover.png, summary_large_image |

## Пріоритетні запити (семантика)

1. школа кібербезпеки / курси кібербезпеки Україна  
2. навчання пентесту / AppSec курси  
3. CTF лабораторія / практика кібербезпеки  
4. курси Python / програмування для безпеки  

Суть сайту збережена: школа, програми, лабораторії, CTF, заявка.

## Що дає ріст у видачі далі (поза кодом)

1. **Google Search Console** — підтвердити домен, надіслати sitemap.  
2. **Контент** — 4–8 статей/гайдів під кластери запитів (кожна з внутрішніми лінками на курси).  
3. **Зовнішні згадки** — профільні спільноти, партнерські пости, каталоги шкіл.  
4. **Швидкість / Core Web Vitals** — вже темна SPA-легка верстка; тримати шрифти з `display=swap`.  
5. **Окремі landing під напрями** — якщо з’являться стабильні SEO-сторінки `/cybersecurity`, `/appsec` (після GSC даних).
