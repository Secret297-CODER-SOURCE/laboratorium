# Nielsen heuristics audit — marketing home + B2B contact

**Продукт:** B2B / B2C платформа навчання IT і кібербезпеки (laboratorium.)  
**Екран:** головна маркетингова сторінка `/` + форма заявки `#contact`  
**Основна дія:** залишити кваліфіковану заявку на навчання (індивідуально / команда / компанія)

Аудит після оновлення до UMO-рівня (колонкова сітка, стриманий hero, B2B-секція, розширена форма).

---

## Проблеми (від критичних до косметичних)

### 1. Низький контраст muted-тексту на темному фоні — ВИПРАВЛЕНО
- **Евристика:** #2 / #4
- **Критичність:** 3 → 0
- **Виправлення:** `--text-muted: #a3a3a3`, `--text-dim: #7a7a7a`.

### 2. Успіх відправки форми лише на кнопці — ВИПРАВЛЕНО
- **Евристика:** #1 / #9
- **Критичність:** 3 → 0
- **Виправлення:** `#contact-form-status` з ok/error станами + `aria-live`.

### 3. Обов’язковість компанії залежить від intent — ВИПРАВЛЕНО
- **Евристика:** #6 / #10
- **Критичність:** 2 → 0
- **Виправлення:** `required` + `*` для corporate/team; server-side ValidationError.

### 4. Hero CTA «Обговорити» і «Обрати програму» конкурують без ієрархії для B2B-байєра
- **Евристика:** #8 Aesthetic and minimalist design; #4 Consistency
- **Критичність:** 2
- **Виправлення:** залишити primary = Get in touch / заявку; secondary = каталог. Уже частково зроблено; у EN-локалі узгодити ті самі пріоритети.

### 5. Навігація «Для компаній» веде в середину сторінки — немає окремого landing state
- **Евристика:** #3 User control and freedom
- **Критичність:** 1
- **Виправлення:** додати `scroll-margin` / короткий sticky subnav у B2B-секції або deep-link `#b2b` з коротким summary у title document fragment.

### 6. Stats-стрічка після hero може відволікати від основної CTA
- **Евристика:** #8 Aesthetic and minimalist design
- **Критичність:** 1
- **Виправлення:** залишити стрічку компактною (як зараз) або показувати тільки після скролу; не повертати цифри у перший viewport.
